# EVE VEX

Public OpenVEX documents published by CVEWatch.

- Website: https://shjala.github.io/eve-vex/
- Machine-readable index: https://shjala.github.io/eve-vex/index.json
- Document URLs: `eve/<exact-version>/openvex.json`, for example `eve/17.0.1-lts/openvex.json` once published.

Each exact LTS version has one stable URL. Publishing a later revision replaces that document and updates its index entry. Other versions remain available. The index includes the document revision and SHA-256 of the exact downloadable bytes. Git history retains earlier publications.

Only the generated OpenVEX document is public; internal analysis inputs and full risk reports are not uploaded. Consult each document for its author, role, assessment scope and status.

GitHub Pages publishes the root of `main`. `.nojekyll` keeps JSON and HTML files unchanged.
